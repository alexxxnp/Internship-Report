#### Product demo

When the website opens, it displays events for users to explore. The navigation bar above the events provides access to the main pages. When users click the heart icon, the event is saved in Saved.
![Events Hub](/images/5-Workshop/12.1.jpg)
![Events Hub](/images/5-Workshop/12.2.jpg)

Events are created through Lambda, and their images can also be changed. The updated images are stored in the Banner folder in Amazon S3.
![Lambda](/images/5-Workshop/12.5.jpg)
![Amazon S3](/images/5-Workshop/12.6.jpg)

When users select an event, the event details page is displayed. This page provides more information about the selected event.
![Event](/images/5-Workshop/12.3.jpg)

The “Add to Google Calendar” button adds the event to the user's Google Calendar. It creates a calendar entry with the event name, date, time, and location, allowing users to set a reminder so they do not forget to attend.
![Google Calendar](/images/5-Workshop/12.4.jpg)

Users can submit their information for the selected event and indicate whether they will attend. The page also displays the number of attendees and non-attendees.
![Event](/images/5-Workshop/12.7.jpg)

The Call for Speakers page allows guests to propose who should speak next and which topic they would like to present.
![Call for Speakers](/images/5-Workshop/12.8.jpg)

The Resources & Labs page provides a learning resource library.
![Resources & Labs](/images/5-Workshop/12.9.jpg)

The Venue page provides the venue map and floor information.
![Venue](/images/5-Workshop/12.10.jpg)

The Network page displays a list of notable engineers.
![Network](/images/5-Workshop/12.11.jpg)

The Certification page helps users quickly choose a group to join.
![Certification](/images/5-Workshop/12.12.jpg)

The Partners & Jobs page displays sponsor information.
![Partners & Jobs](/images/5-Workshop/12.13.jpg)

The Live Q&A page allows users to submit opinions or feedback.
![Live Q&A](/images/5-Workshop/12.14.jpg)

The Digital Badges page verifies check-in information and issues digital certificates or badges to event attendees.
![Digital Badges](/images/5-Workshop/12.15.jpg)
![Digital Badges](/images/5-Workshop/12.16.jpg)

The My Passes page displays tickets after registration and saves events that users want to keep track of.
![My Passes](/images/5-Workshop/12.17.jpg)
