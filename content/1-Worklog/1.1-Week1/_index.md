### Week 1 Objectives:

* Understand the fundamentals of Cloud Computing and the AWS service ecosystem.
* Get familiar with the AWS Management Console interface and set up AWS CLI configuration.
* Practice launching and managing EC2 compute resources and basic EBS storage.

### Week 1 Achievements:

* Mastered Cloud Computing concepts and gained a solid understanding of core AWS service categories (Compute, Storage, Networking, Database, Security).
* Successfully registered and activated an AWS Academy Learner Lab account for hands-on practice.
* Proficiently navigated the AWS Management Console to locate, access, and manage cloud services via the web interface.
* Successfully installed AWS CLI v2 on local machine and properly configured credentials (`Access Key`, `Secret Key`, `Default Region`).
* Executed basic AWS CLI commands to verify account setup and list EC2/S3 resources.
* Successfully launched a Linux EC2 Instance, configured proper Security Groups, and established secure SSH connections.
* Completed creating, attaching, and mounting EBS Volumes to the EC2 server.
